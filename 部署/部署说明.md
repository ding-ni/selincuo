# 部署

当前为P03本机只读空间资料原型，页面和API由一个FastAPI服务同源提供。默认仅绑定127.0.0.1，不包含账户、任务执行或业务预警发布能力。

## 当前机器启动

在项目根目录执行：

```powershell
powershell.exe -ExecutionPolicy Bypass -File '部署/启动平台.ps1'
```

默认地址为 http://127.0.0.1:8765 ，API文档为 http://127.0.0.1:8765/docs 。脚本检查端口占用，冲突时使用 `-Port 8766`；隐藏启动服务并在独立中文批次目录保留日志，输出PID。停止服务可针对已核实的该PID执行 `Stop-Process -Id <PID>`，不会清理日志或成果。启动脚本使用UTF-8 BOM，兼容Windows PowerShell 5.1中文路径。

当前依赖已在机器上验证，不需要重新安装。Python 3.9.17及直接依赖见[requirements.txt](requirements.txt)，前端固定为Vue 3.5.13、MapLibre GL 5.3.0、Lucide 0.468.0；下载地址、大小和SHA-256见[前端依赖锁定.json](前端依赖锁定.json)。首期采用浏览器版Vue及JavaScript，无打包过程；TypeScript/Vite迁移待后续模块扩大时实施，届时需审查缓存和清理行为。

## 新机器与资料恢复

Git不含原始资料、标准批次或浏览器依赖。缺数据时API返回503，不会自动导入演示数据。恢复来源文件前先核对复制清单、目标范围与哈希，禁止覆盖、移动或清空目录。Python环境需按依赖清单单独准备，安装前检查已有环境及工具的替换/清理行为。

浏览器依赖可执行 `python '工具/准备前端依赖.py'`，只新增缺失文件，已有文件按锁定清单核验，不清理缓存或替换旧文件。地图资源与库准备完成后，页面运行不访问在线底图、字体或CDN。

空间标准化示例：`python '工具/空间标准化.py' --batch 空间标准化-20260916-03`。必须先确认该批次不存在；不能重跑到既有目录。源文件须符合本地 `文档/核查记录/复制校验清单.csv`，工具对49项选定来源进行前后哈希验证，输出GeoJSON、空间目录及质量报告。默认服务读取 `数据/标准数据/空间标准化-20260916-02`，可用环境变量 `SELINCO_DATA_DIR` 指向已核验的独立标准目录；不采用“最新文件夹”自动切换。

## 检查与边界

```powershell
python -X utf8 '测试/空间接口验证.py'
python -X utf8 '测试/浏览器验证.py'
```

浏览器检查需要上述服务已运行及现有Playwright Chromium；可用 `--url http://127.0.0.1:8766` 指定地址。测试输出新增至 `成果/测试验证` 独立批次，保留成功及失败产物。模型水量守恒、独立样本验证和真实发布流程尚未实施，不属于本期检查结果。

公开静态资源仅限 `前端/页面` 与 `前端/依赖`；不暴露项目根目录、原始SHP、签章件或核查全文。本机服务无鉴权，尚不适合对外部署。标准图层每次读取校验SHA-256，目录缺失、损坏及图层校验失败均显式报错。

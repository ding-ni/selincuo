# 算法路线与科学验证

## 选择原则

任务书已经规定研究方向和部分具体方法。下面区分“任务书要求”“工程起步方法”和“正式研究能力”，起步简化不代表削减最终任务。优先使用成熟GIS、统计、优化和水动力工具；具体求解器须核查许可、运行环境、数值格式与接口能力，再登记版本。本阶段不声称已选定可满足全部要求的求解器。

## 算法模块与依赖

| 模块 | 方法与性质 | 必需输入 → 输出 | 验证与约束 |
|---|---|---|---|
| A01 空间与气象预处理 | GIS修复/重投影、掩膜、面积权重、重采样；方法为工程建议 | 边界、DEM、气象和元数据 → 标准网格/河湖拓扑/驱动 | 栅格守恒、插值留站验证；类别用最近邻，降水总量检查，禁止用分辨率提升冒充信息提升 |
| A02 湖泊水域反演 | Landsat、NDWI+Otsu，任务书第10页；云、雪冰与阴影掩膜 | 多期影像与验证岸线 → 湖界、面积、质量掩膜 | IoU/F1、岸线位置和面积误差；冻结期单列；目标1990—2025，不拼凑伪连续数据 |
| A03 河湖测高 | 波形重订、异常回波筛选、多卫星偏差校正，第9页；激光与雷达分支处理 | 卫星测高、轨道、地球物理改正及实测 → 水位序列和误差 | 统一垂直基准与时间配对，对应K02/K04；实测样本不能同时用于拟合与独立验证 |
| A04 遥感流量 | Manning等明渠方程与机器学习参数优化，第9页 | 水位、断面、水面宽、坡降、糙率及测流 → 流量和区间 | 对应K03；缺断面/糙率会造成不可辨识性，不能仅由河宽给可信流量 |
| A05 冰川变化 | 边界解译、表面温度、大气校正、D-InSAR/MAI/SBAS，第9页 | 光学/SAR影像及外业约束 → 面积/温度/形变时序 | 独立冰川边界、位移验证；SAR去相关、大气误差、轨道几何须记录；位移不是消融量 |
| A06 冻土反演 | SBAS形变与深度学习活动层厚度，第10页；简单统计/RF作对照属建议 | SAR、土壤、气象、地形、实测活动层 → 厚度/季节形变/不确定性 | 空间分块与时间外推验证，GNSS和样点独立检验；形变不等同活动层厚度 |
| A07 冰川积雪过程 | 度日冰川算法，积雪升华、风吹雪及多相态模块，第13页 | 温度、降水、冰雪分布及参数 → 融水、雪储量、冰储量变化 | 融雪先消耗雪储量，冰川消融受冰储量约束；降水相态、风场与能量假设清楚 |
| A08 冻土水热与产流 | 土壤水/冰/热运移、包气带动态、蓄满—超渗动态组合，第10、13页 | 土层、热力参数、土温土湿、气象 → 未冻水、入渗、各水源径流及交换 | 冻融相变、冻土入渗和各储量守恒；新安江仅作湿润区产流基准或可替换模块，不能独立代表完整寒区模型 |
| A09 汇流与湖泊平衡 | 串并联非线性水库、河网多边形、地表地下水湖泊交互，第10、13页 | 网格径流、拓扑、湖盆曲线、蒸发、地下水 → 入出流、湖位、库容和交换量 | 检查流域闭合、岸线变化及回水；四入湖流域以外的补给项显式登记 |
| A10 水动力与耦联 | 河道1D、平面2D、溢口局部3D；Abbott六点隐式/Roe/PISO，第10页 | 断面/地形、糙率、初始水位、上下边界 → 水深、流速、淹没及到达时间 | 湿干界面、静水保持、CFL/稳定性、网格与时间步收敛；通过边界流量和水位迭代验证双向耦合 |
| A11 参数率定与不确定性 | SCE-UA/差分进化等全局优化及敏感性分析为建议 | 独立划分的驱动、观测、参数范围 → 参数版本及可信范围 | 先可辨识性与敏感性再高维率定；NSE/KGE/RMSE/PBIAS分变量报告，不只挑最高分 |
| A12 集合风险与预警 | 集合概率预报、危险度与易损度，第8、11页 | 成员结果、承灾体、阈值与暴露 → 风险单元、超阈概率、预警草稿 | 有效成员数、可靠性、Brier/CRPS、漏报空报及提前量；不能将确定性模型包装成集合 |

遥感重处理可调研SNAP/ISCE/MintPy等成熟工具，但应核实其是否覆盖指定方法；水动力可调研TELEMAC、HEC-RAS、OpenFOAM等适配方式。举例不等于已确定选型，更不能将不同软件的默认数值格式宣称为任务书指定格式。

## 核心水量合同

湖泊每个时间步的基本记账为：

```text
V(t+Δt) - V(t)
  = 湖面降水体积 - 湖面蒸发体积
  + 入湖河流体积 - 出湖/漫溢体积
  + 地下水净交换体积 + 其他有证据的净补给体积
```

流量以m³/s输入时乘时间步秒数；湖面降水若为mm，需要乘0.001和对应时段湖面积m²。面积随水位变化，使用与求解方式一致的时间步代表面积或迭代值。由经验证的V(h)、A(h)关系求水位，不能仅用一个常面积把累计入流直接加到固定湖位。

冰川融水若已进入坡面—河网汇流，不能再直接加一次入湖量。地表与地下水的交换必须在对应储量方程中一正一负记账；未知地下水交换不得作为任意闭合误差项而不披露。

闭湖状态出流应符合已核实出口条件；达到漫溢阈值后，由溢口几何与下游水位约束出流。下游回水可能改变出流和湖位，因此单向传递流量只能称初步串联，不能称已实现双向水文水动力耦合。

## 模型推进层次

1. 输入可信层：真实气象、入流/湖位观测及湖盆关系到位；先检查时空、量纲和闭合。现有资料不足时先完成资产规范与质量修复，不捏造输入。
2. 水量基准层：可用汇总入流或经验证的简化径流建立独立湖泊平衡基准。以质量守恒和时序对齐验证软件正确性，标为基准而非完整R03。
3. 寒区过程层：逐步耦合冰川、积雪、冻土、蓄超组合、地下水与河湖交换；保存启用模块及替代假设，进行模块消融比较。
4. 多维耦合层：先验证河道1D与近湖2D，再开展局部3D与双向交换；局部3D范围由溢口水力问题决定，不对整个流域盲目做3D。
5. 预警检验层：在历史起报可用资料上滚动回报，接入集合预报，分7天、15天评估。只有通过验证并具备真实运行资料后才进入业务发布流程。

## 科学验证清单

| 对象 | 必做证据 |
|---|---|
| 基础数据 | 完整率、缺测段、站点独立性、空间覆盖、CRS与高程基准、质量标志 |
| 遥感反演 | 独立样本、观测匹配规则、样本量、误差分布与产品有效期；训练或偏差订正样本不能泄漏 |
| 水文模型 | 预热期、率定期、验证期、跨年份表现；径流及湖位共同约束，各水量项闭合 |
| 水动力 | 静水、渠道或溃坝等成熟基准；体积误差、非负水深、湿干稳定性、网格和时间步敏感性 |
| 耦合界面 | 时间步同步与通量积分、接口两侧收支、交换方向、迭代收敛、回水反馈对照 |
| 机理研究 | 基准与消融实验、因子敏感性、参数可辨识性、替代解释和不确定性，避免仅凭相关下结论 |
| 风险产品 | 危险度/暴露度/易损度分别注明依据；缺承灾体时只输出危险度，不宣称经济损失 |
| 预警能力 | 预报起报截断、逐预见期技巧、概率校准、历史事件命中与误报、运行延迟和缺测情形 |

任务书没有给出所有模型NSE、淹没IoU或运行耗时门槛。应在实际资料规模和验证方案明确后约定，不编造“验收要求NSE≥0.9”等指标。K02与K03等已有硬指标按验收映射执行。

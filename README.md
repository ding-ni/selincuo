# 色林错预警预报平台

0.12.0源码版，更新于2026-10-29。本轮在审查分支继续实现“杜加流量率定 → 陆域共享水文参数 → 固定来水率定湖泊蒸发系数 → 采用连续成果”。率定页按资料时段、参数、计算、结果四步操作；日常页面保留采用方案和用户方案，开发试验归入后台。实施状态与实际数值见[现行台账](docs/整改执行台账-现行.md)。

## 启动

本机双击根目录 **启动平台.bat**。读取本机 `config/active-workspace.json`，核验版本、工作区与启动源码摘要后打开 **8882**。8879仍可能是旧0.6.0服务，不作为本版入口。

工作区配置参考[示例](config/active-workspace.example.json)。本机沿用 `build/grid-revision-20261026/workspace`，不复制或迁移整套资料。源码修改后，在 `frontend` 执行 `npm run build` 并重启服务。命令行入口：

~~~powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./scripts/启动源码平台.ps1
~~~

本轮未构建EXE，既有安装包不会因源码更新而升级。七个页面的操作见[现场手册](docs/现场使用手册-现行.md)，状态见[执行台账](docs/整改执行台账-现行.md)。

## 两阶段率定

22项水文参数分为陆面9项、雪冰9项和汇流4项。先做2024/2025双向分年检验，再用全部440个有效流量日确定共享参数；以2020开始的连续预热状态计算。三起点种子42、142、242，分组交替两轮后联合细化，每次拟合基础预算18000次，持续改善时追加至36000次。停止后保留搜索状态，可以接续。

第二阶段固定陆域参数和入湖来水，先以2021—2024年湖位确定蒸发转换系数并检查2025—2026年，再用全部有效湖位确定正式值。大屏展示从2021-04-23至2026-10-20的实际连续成果；起算日采用日值12时代表，首完整湖位日为4月24日。已用过的2025/2026资料称时间检验，全部资料重拟合另列。

本轮成果`JOB-4934a5d35c9344a59353`已保存并采用，重启后保持。三次流量拟合共86117次评价，全部440日NSE0.747086；正反向分年检验NSE0.353990/0.523318。湖面系数达到1.5上限，全部资料湖位RMSE1.240698米；旧方案的湖位分数更好。本轮采用体现已批准的两阶段流程，实际参数、未收敛状态及新旧对比见[交付证据](docs/evidence/两阶段率定交付-20261029.json)和[正式方案](config/operational/两阶段采用方案-20261029.json)。

新方案计算范围保留四河原SHP边界及扎加内部杜加/其余区域，加入严格地形判定的湖周来水；无去向的约2061.29 km²仅作背景。陆域采用同一组水文参数，各计算单元保留独立气象、高程、面积和冰川覆盖。杜加为扎加内部评价断面，入湖合计仅计扎加总量一次。

## 日常业务

- 主站资料从2021-04-23独立查询；四岸覆盖不截断主站。
- 新建或复制方案、编辑、试算或率定、从成功成果保存完整参数、让方案采用参数。
- 参数采用与率定初值分别设置。历史成果关联当次真实输入，不被当前编辑覆盖。
- 观测缺测只影响对照和评价，不中断已初始化的模拟。更新评价观测不重设父状态湖位。
- 成果可命名保存、比较、导出、回收和恢复。回收站可预览后一次确认永久删除独占资源；共享、采用和活动引用受保护，不自动清空。
- 方案点击保存后写入本机工作区，重开仍在；方案和已保存参数可回收、恢复，已有成果和采用参数引用保留。
- 观测上传与气象日期更新完成后，可使用原参数继续模拟。

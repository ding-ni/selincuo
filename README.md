# 色林错预警预报平台

0.12.0源码版，更新于2026-10-28。平台提供资料查询、方案与率定、连续历史模拟、成果管理和过程状态查看。第三轮修复大屏、共享地图、连续成果覆盖及对象永久删除；按用户优先插入项完成[参数审计与移植](docs/新安江参数审计与传递-20261028.md)。旧采用方案、冻结成果和科学发布记录保留原身份。

## 启动

本机双击根目录 **启动平台.bat**。读取本机 `config/active-workspace.json`，核验版本、工作区与启动源码摘要后打开 **8882**。8879仍可能是旧0.6.0服务，不作为本版入口。

工作区配置参考[示例](config/active-workspace.example.json)。本机沿用 `build/grid-revision-20261026/workspace`，不复制或迁移整套资料。源码修改后，在 `frontend` 执行 `npm run build` 并重启服务。命令行入口：

~~~powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./scripts/启动源码平台.ps1
~~~

本轮未构建EXE，既有安装包不会因源码更新而升级。七个页面的操作见[现场手册](docs/现场使用手册-现行.md)，状态见[执行台账](docs/整改执行台账-现行.md)。

## 内置方案

原内置方案及下述2023起成果继续保留。新建方案默认先用杜加流量率定共享水文参数，湖位仅评价；可显式另建面积尺度假设对照，逐区参数和每个HRU来源可查。25项参数全部展示，22项可作条件流量搜索，分组与多起点预算可配置；两个裸冰升华参数及湖面系数禁止混入杜加流量优化。原值来源、触边、未收敛与初态影响均如实保留，不声称全域已独立率定。

本轮独立保存的A0/A1/A2完整成果已覆盖2021-04-23—2026-10-20，2020为内部预热、4月24日为首完整湖位日。原采用配置不自动替换；[对照收据](docs/evidence/杜加参数传递真实对照-20261028.json)保留真实身份和指标。潜在水面蒸发1.0近似下湖位偏差明显，不能以蒸发拟合掩盖来水/收支问题。

真实两起点分阶段率定已完成158次评价，整体未收敛且时间留出流量表现下降，保存为研究候选。参数保存/采用/重新打开及7小时末状态续算已通过，见[业务链收据](docs/evidence/流量率定参数采用与续算-20261028.json)；这项链路通过不表示新参数优于原值。

[完整配置](config/operational/continuous-builtin-v1.json)保存全局和杜加分区参数、31组空间、汇流方式、湖面降水订正、初始化和当前成果编号。31组按排水分区、500米高程带、冰川/非冰川组织，覆盖1599个来源单元的全部面积权重；气象先聚合再进入既有非线性核心。地图显示其实际支持面。

陆面从2023-01-01起算。湖位采用2023-04-20日值按当日12时代表的4544.03米锚点，首个完整湖位日2023-04-21。当前成果计算至2026-10-21 00时，即最后完整日2026-10-20。这个锚点不是经核实的瞬时测量时刻。

90米地形复核后，2024/2025连续湖位RMSE约0.06432/0.06499米（232/255日），杜加NSE约0.52909/0.72552。与旧版本相比有升有降，详见[本轮数值对照](docs/evidence/第二轮空间完整期对照-20261028-152049-2fca47.json)。采用依据包括已有对照、连续性、收支、成本和参数可复现性，不宣称全局最优；2025/26不称未参与开发的独立检验。原受保护窗口成果、C1参考及原门槛未改写。

## 日常业务

- 主站资料从2021-04-23独立查询；四岸覆盖不截断主站。
- 新建或复制方案、编辑、试算或率定、从成功成果保存完整参数、让方案采用参数。
- 参数采用与率定初值分别设置。历史成果关联当次真实输入，不被当前编辑覆盖。
- 观测缺测只影响对照和评价，不中断已初始化的模拟。更新评价观测不重设父状态湖位。
- 成果可命名保存、比较、导出、回收和恢复。回收站可预览后一次确认永久删除独占资源；共享、采用和活动引用受保护，不自动清空。
- 方案点击保存后写入本机工作区，重开仍在；方案和已保存参数可回收、恢复，已有成果和采用参数引用保留。
- 观测上传与气象日期更新完成后，可使用原参数继续模拟。

## 资料与资源

主站为工作基准。四岸缺水准联测和零点资料，保留原值与“基准待核”，不参与统一绝对湖位率定。各站基准可按生效时段登记查询，未知零点仍为空。

ERA5-Land为背景气象。主站2024年降水用于湖面比例订正0.5336700706945834，其余站点未伪称融合进陆域。首页模型降水与雨量卡采用面积加权并含湖面的模型值；地形叠加气象格网显示再分析原值，单独标识。首页为左侧雨情和四岸观测、中央地图、右侧四河及湖周直接来水、湖泊收支，地图保持真实比例。

2020—2022年真实ERA5-Land补数已完成，当前统一资料库为 `INPUT-fc731ba1bf2b5e79d3e03d92`，完整日2019-12-31—2026-10-20，共59687个逐时时刻、535格。用户选择方案和时期后，后台自动匹配资料、核对一年预热并安排有效湖位起算；2021年实际试算与续算已通过。主站最早合格日值2021-04-23按12时代表起算，完整湖位自2021-04-24起，不补造之前的湖位。

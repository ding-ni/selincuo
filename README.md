# 色林错预警预报平台

0.11.0源码版，更新于2026-10-28。平台提供资料查询、方案与率定、连续历史模拟、成果管理和过程状态查看。本轮依据已有真实资料和E3对照，内置“色林错综合模拟方案”。旧冻结成果和科学发布记录保留原身份。

## 启动

本机双击根目录 **启动平台.bat**。读取本机 `config/active-workspace.json`，核验版本、工作区与启动源码摘要后打开 **8882**。8879仍可能是旧0.6.0服务，不作为本版入口。

工作区配置参考[示例](config/active-workspace.example.json)。本机沿用 `build/grid-revision-20261026/workspace`，不复制或迁移整套资料。源码修改后，在 `frontend` 执行 `npm run build` 并重启服务。命令行入口：

~~~powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./scripts/启动源码平台.ps1
~~~

本轮未构建EXE，既有安装包不会因源码更新而升级。七个页面的操作见[现场手册](docs/现场使用手册-现行.md)，状态见[执行台账](docs/整改执行台账-现行.md)。

## 内置方案

[完整配置](config/operational/continuous-builtin-v1.json)保存全局和杜加分区参数、31组空间、汇流方式、湖面降水订正、初始化和当前成果编号。31组按排水分区、500米高程带、冰川/非冰川组织，覆盖1597个来源单元的全部面积权重；气象先聚合再进入既有非线性核心。地图显示其实际支持面。

陆面从2023-01-01起算。湖位采用2023-04-20日值按当日12时代表的4544.03米锚点，首个完整湖位日2023-04-21。当前成果计算至2026-10-21 00时，即最后完整日2026-10-20。这个锚点不是经核实的瞬时测量时刻。

2024/2025连续湖位RMSE约0.06376/0.06231米（232/255日），杜加NSE约0.52909/0.72553。采用依据包括已有对照、连续性、收支、成本和参数可复现性，不宣称全局最优；2025/26不称未参与开发的独立检验。原受保护窗口成果、C1参考及原门槛未改写。

## 日常业务

- 主站资料从2021-04-23独立查询；四岸覆盖不截断主站。
- 新建或复制方案、编辑、试算或率定、从成功成果保存完整参数、让方案采用参数。
- 参数采用与率定初值分别设置。历史成果关联当次真实输入，不被当前编辑覆盖。
- 观测缺测只影响对照和评价，不中断已初始化的模拟。更新评价观测不重设父状态湖位。
- 成果可命名保存、比较、导出、回收和恢复，共享资源有引用保护。
- 方案点击保存后写入本机工作区，重开仍在；内置方案和用户方案均可回收、恢复，已有成果保留。
- 观测上传与气象日期更新完成后，可使用原参数继续模拟。

## 资料与资源

主站为工作基准。四岸缺水准联测和零点资料，保留原值与“基准待核”，不参与统一绝对湖位率定。各站基准可按生效时段登记查询，未知零点仍为空。

ERA5-Land为背景气象。主站2024年降水用于湖面比例订正0.5336700706945834，其余站点未伪称融合进陆域。首页模型降水与雨量卡采用面积加权并含湖面的模型值；地形叠加气象格网显示再分析原值，单独标识。首页为左侧雨情和四岸观测、中央地图、右侧四河来水与湖泊收支，地图保持真实比例。

2020—2022年真实ERA5-Land补数已通过本机CDS配置实际启动，当前任务为`JOB-9cc92d0b181147bfabcc`，尚未全段下载和登记。2020年用于较早时段的预热资料准备，不能据此称长期初态已通过。已完成月份、续传和下一接续操作见[最新阶段记录](文档/阶段操作记录.md#2026-10-28大屏与真实气象补数接续包)，任务中心可查看实时进度。仍需四岸水准资料、长期初态和独立冰雪证据。约2340.743平方公里未核实排水区独立记账，不补零、不并入已核实入湖量；杜加在扎加内仅计一次。

# 色林错预警预报平台

独立的色林错历史水文与湖位计算工程。项目标识 `selinco`，默认本机端口 `8879`。源码、数据库和安装包均独立管理。

业务链：真实观测与 ERA5-Land → 高程带冰雪过程与半分布式新安江 → 四河及湖周入湖径流 → 定面积湖泊水量平衡 → 无冰期湖位。

## 启动

Windows 安装包位于 `releases`。安装后运行“色林错预警预报平台”，浏览器打开 `http://127.0.0.1:8879/`。本机已运行色林错服务时会打开该实例。安装目录下 `workspace` 是用户资料，升级和卸载均保留。请用“工作区与系统”退出服务。

当前独立工程已在 `运行程序` 安装完整环境，直接双击根目录 `启动平台.cmd` 即可使用 EXE 启动，不需要安装 Python。根目录源码的 `workspace` 与 `运行程序/workspace` 分别保留；日常使用以程序“工作区与系统”显示的实际目录为准。迁移计算资料请使用平台备份/恢复，不混合两个数据库。

源码运行：Python 3.9 及以上，先 `python -m pip install -r requirements.txt`；在 `frontend` 执行 `npm ci` 和 `npm run build`；返回项目根目录执行 `python app_entry.py`。也可运行 `启动平台.cmd`。所有文件均通过项目内相对目录定位，不连接原平台。

离线交付的 EXE 已包含运行环境；联网只在主动下载气象资料时需要。离线源码重装依赖需要预备 pip/npm 缓存或镜像。

## 第一次操作

1. 在“监测资料”核对站点、水位基准、停测标记和雨量观测覆盖。原始时间与文本始终保留。
2. 在“模型与资料”扫描、导入 Excel；已有原始资料种子不重复入库。上传文件名需包含变量名称和年度。
3. 将真实 ERA5-Land NetCDF 上传，或运行 `python scripts/download_era5.py --years 2023 2024 2025 --halo`。CDS 认证使用用户自己的 `~/.cdsapirc`，工程不保存密钥。下载默认串行提交，保留分段下载进度。
4. 点击“登记真实气象输入”。输入版本必须连续，所有变量覆盖完整；不能用缺测补零通过检查。可按独立连续片段登记不同输入。
5. 在“历史模拟”选择真实输入和时段，先运行未率定基线。人工修改参数后选择“人工试调运行”。保存命名方案、命名参数及成果备注。
6. 完整历史资料就绪后，在“参数率定”使用 2023 年预热、2024 年杜加流量搜索产汇流参数；再选择成功的同输入版本成果，冻结流域参数，仅率定湖面蒸发系数。评价次数预算耗尽不等同于收敛。
7. 在“计算成果”比较日流量、湖位和水量诊断，导出 CSV、逐时 NPZ、状态 JSON。在“过程与状态”查看计算单元状态，并在相同输入、空间、参数、模型及观测快照下续算。

## 目录

| 目录 | 内容 |
|---|---|
| `frontend` / `backend` | Vue 网页与 Python 本机服务、完整数值内核 |
| `config` | 独立应用身份与固定业务约定 |
| `data/raw` | 仅色林错原始资料副本；原件不移动 |
| `data/derived/spatial` | 空间单元、精确面积权重及展示图层 |
| `workspace/database` | SQLite WAL 数据库 |
| `workspace/observation-sources` | 原始 Excel 按 SHA256 快照归档 |
| `workspace/inputs/products` | 已登记的不可变真实气象输入 |
| `workspace/tasks` | 冻结请求、日/小时成果、检查点与错误日志 |
| `workspace/exports` | 导出与便携备份 |
| `seed` | 干净的色林错资料种子，禁止放入开发任务和状态 |
| `docs` | 来源清单、实现说明、验收记录与实际计算报告 |
| `installer` / `scripts` | PyInstaller、Inno Setup 与构建、下载、检验工具 |
| `releases` | 安装 EXE、发布清单及摘要 |

Git 只保存源码、配置、测试与文档；原始/派生大文件、下载、工作区、构建产物和安装包不进入 Git，需本地备份。未配置远程推送。

## 计算边界

0.1° 为气象尺度，500 m 高程带与冰川/陆面交集为计算单元；二者分别管理。当前温度高程参考为源 DEM 格网平均值，仍需 ERA5 地形进一步核验。杜加是独立内部控制断面，总入湖流量不重复加入杜加流量。四岸水位在基准统一前分开展示。

湖泊定面积，仅保存相对蓄水变化。地下水净交换、外流暂为零，冰川面积固定。每个可靠湖位窗口仅初始化一次；日均资料缺乏精确时刻时采用中午日均锚点并记录，不将初始化当天纳入评分。短片段起点若晚于窗口锚点，将没有该窗口湖位模拟，需回放至锚点。

2023 预热，2024 率定，2025 独立验证，2026 在实际资料覆盖内延伸。软件能运行与模型效果达标分别验收。无完整真实驱动不能声称完成年度率定验证；无匹配观测的指标为缺项。滚动预报、湖盆面积—水位—容积关系、冻土和 30 m 河网不在本版执行范围。

## 维护、构建与测试

运行 `python -m unittest discover -s tests -v`。真实 NetCDF 测试在文件缺失时明确跳过，不能替代真实资料验收。Windows 构建：`powershell -File scripts/build_windows.ps1 -Python python`；首次构建先执行 `python scripts/make_seed.py`。若种子目录已存在，需另选空目录，不覆盖历史种子。

清理分两步：先移入平台回收站，可恢复；最终清理需预览确认并通过 Windows 回收站执行，受引用或已命名状态保护。不会回退为永久删除。

备份在任务结束后执行，包含 SQLite 一致性快照、原始观测快照、登记输入及成果状态。恢复到新目录、校验摘要后，下次启动切换。跨安装迁移时请同时携带本工程 `data` 空间资料和对应版本源码；空间版本不同的备份会拒绝切换。修改 `config/active-workspace.json` 可选择已有工作区；`SELINCO_WORKSPACE` 环境变量优先。

模型代码的来源与移植范围见 `docs/实现与来源说明.md`；原始文件 SHA256 见 `docs/source-manifest.json`；实际完成程度以 `docs/验收记录.md` 为准。

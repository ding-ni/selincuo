## 地图问题与修正

此前四河文字使用手写坐标，与原始GIS不对应：扎加藏布与扎根藏布东西颠倒，波曲藏布与阿里藏布文字偏离各自分区。原始流域数据及模型面积未因这一显示问题互换。

四河名称沿用原始GIS：扎加藏布、扎根藏布、波曲藏布、阿里藏布。新版标签取对应分区最大多边形内部最宽处，必要时挪动文字框并以引线连接真实锚点；不再手填文字地理坐标。河线保留原始 basin_id 和 basin_cn，便于核对所属分区。

每个分区使用固定颜色，与左侧来水卡片、标注及图例一致；湖周补充区采用斜线纹理。所有气象和积雪图层之上重绘分区边界。图层切换不再覆盖分区边界。杜加控制区为可单独开启的内部断面控制范围。

地图按照真实控制域边界、容器尺寸和统一投影比例自动适配；支持全流域、湖区、缩放和平移，比例尺随视图改变。响应窗口尺寸变化，保持完整域与合理留白。模型与资料页共享同一地图。

## 业务逻辑

- 完整历史输入优先于早期片段；工作台可一键选择完整历史（含预热）。保留用户已保存的草稿和方案。
- 全年计算结束时刻包括次年1月1日00时，保留年末完整日。移除起算点前只有一个午夜样本形成的伪日和伪年份。
- 湖位平均、流量、融雪、融冰、湖面收支的日期采用统一日界。完整计算保存每日气象小时数，正式报告要求每天24小时。
- 成果页明确选择评价年份，优先展示2025独立验证，不再把首个匹配年份的预热指标放在顶部当作默认效果。
- 真实未率定基线 → 2024杜加产汇流预算搜索 → 固定流域参数、搜索湖面蒸发系数 → 固定参数2025独立评价。2025与2026观测不参与搜索。
- 无独立流量观测的河流仍显示为未独立验证；无实时数据和未来驱动时不生成实时预警或预报。

# v0.3.0 湖情大屏

用户确定：日常浅色、汇报深色；地图和大屏是本轮重点，其他页面维持南安溪的成熟业务逻辑，按色林错过程适配。

## 参考及适配

参考原平台 `RealtimeView.vue` 的中央地图、两侧信息区、选站详情与回放时间轴；参考 `BasinMap.vue` 的图层开关、缩放复位、格网与地理图层区分；参考 `TimelineBar.vue` 的播放、前后步进、速度与日历定位。独立项目不复制南安溪数据和原平台色林错演示过程。

大屏围绕色林错湖位设置六项指标：模拟或实测湖位、匹配主站实测、总入湖流量或杜加实测、连续模拟日湖位变化、固定湖面面积、冰川范围。主站最近可靠观测单独标明日期和“历史观测，非实时”，不将最近值补入缺测日期。

中央地图使用真实控制域、湖泊、冰川、500 m高程带单元，叠加已有1 km地形与河网作为展示背景。新增背景及简化展示文件不修改精确面积权重、空间版本和汇流方案。SVG经纬度投影按纬度近似校正横向比例，面积仍来自EPSG:6933核算。

左侧切换日降水、日均气温、日蒸发能力、日末雪水当量和静态流域分区，控制地形、河网、冰川、测站及杜加控制区。地图支持缩放、平移、复位、测站点选与键盘选择。四岸无核验坐标时只显示列表和数值，不虚构地图位置。

右侧展示主站与四岸湖情、湖泊水量收支和选中测站过程。底部为湖位、来水、冰雪过程图，可点击日期联动回放。通过“大屏→完整成果”“大屏→原始资料”“业务工作台→大屏”衔接原有流程。

## 数据约束

- 观测回放与模型回放分别标识；模型中的主站、杜加对比采用该成果冻结的观测，避免将后续修订静默替换为原评价资料。
- 格网日统计为北京时间日内24个小时末值 `(当日00时，次日00时]`，降水和蒸发能力求和，气温求均值。缺任一小时或数值不完整时地图为空，不补零、不沿用其他日期。
- 全控制域和湖面格网均值使用精确面积权重。气温图为原格网基准，不标为已高程修正的计算单元温度。
- 积雪图展示模型日末雪水当量，面积加权计算；固定冰川边界不当作积雪实测。所选成果无日末状态时明确留空。
- 湖泊收支仅在有效观测演算窗口展示；不足24小时的初始化日明确标注窗口内累计。融雪、融冰诊断已包含在来水中，不再次加入湖泊收支。
- 实时遥测与7—15天预报仍未接入；预警阈值待业务核定，不输出“正常/安全”等无依据等级。
- 软件更新保持原计算记录；后端实现身份变化时，状态续算仍执行严格身份核验，旧状态可能需要恢复条件重新计算。

## 验收

针对性测试包括24小时末日界、缺时刻留空、真实格网面积统计、观测修订缓存、回放日期不借用最近实测、湖泊收支单位和缺测。保留此前数值、续算、水量守恒及独立年度评价测试。

浏览器需核对浅色/深色、1920×1080整屏、常用桌面与窄屏、图层切换、点选主站/杜加、缺测日期、日期步进/播放暂停、全屏退出及工作台链接。EXE需核对新接口、实际历史过程及旧工作区保留。

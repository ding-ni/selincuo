# 色林错预警预报平台 v0.7 使用手册

## 启动

安装完成后从桌面或开始菜单启动。平台在本机运行，默认打开 `http://127.0.0.1:8879/`。第一次启动会建立只包含色林错站点、观测和气象输入的 SQLite 工作区。

## 历史模拟

进入“历史模拟”，选择要查看的完整日期范围并运行“色林错标准历史方案”。方案、模型参数、冰雪过程、汇流结构和湖泊配置已内置。后台从2023年统一起点连续预热，日期选择决定展示和评价窗口。运行后可查看湖位、入湖来水、水量收支，导出日过程，或转到“计算成果”比较和归档。

内置方案使用随安装资料提供的 ERA5-Land 历史输入和观测。超出驱动覆盖范围的日期不能计算；实时遥测、未来气象预报和预警阈值不在v0.7能力范围内。

## 资料和维护

“监测资料”查询站点观测；“模型与资料”查看当前输入、空间分区和内置方案。添加观测或NetCDF时请使用“工作区与系统”中的资料更新入口。模型检查通过后由平台自动整编与登记。

工作区资料和成果保存在安装目录的 `workspace` 中。升级前使用平台的“备份并下载”；卸载默认保留工作区。迁移到另一台计算机时，通过“恢复备份”恢复到新目录，不复制开发任务数据库。

## 模型适用范围

v0.7提供历史模拟。2024杜加流量和2025留出期资料用于方案检验；2025曾在此前开发中查看，不能称为全新外部测试。其他主要河流没有独立流量验证，当前也缺少雪水当量、冰川质量平衡、实测湖面蒸发和现场冰情资料。湖位计算在可靠观测窗口使用观测水位条件起算，不等同于未来水位预报。参数指标和边界见《色林错内置方案与业务流程-v0.7.md》。

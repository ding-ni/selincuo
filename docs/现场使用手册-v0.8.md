# 色林错预警预报平台 v0.8 使用手册

本手册对应2026年10月25日更新的源码业务前端。现有EXE未在本轮重建，旧安装版的页面可能不同。安装版常规端口为8879；本轮源码开发预览为5174，连接8881的隔离验收工作区。

导航依次为“湖情总览、监测资料、参数率定、历史模拟、计算成果、模型状态、模型资料、系统管理”。标准方案及标准成果开箱可用，参数率定不是日常模拟的前置步骤。

## 湖情与资料查询

“湖情总览”默认回放标准成果，中央地图支持全流域和湖区视角、缩放拖动、图层、浅深色与全屏。两侧展示湖位、四岸水位和入湖来水，底部统一选择回放日期；更多过程按需展开。“站点监测”使用各站实际资料，不表示实时遥测。

“监测资料”先选择测站，再选择该站实际拥有的要素。日期默认使用实有时段；降水为柱状图，水位和流量为折线，缺测日留空。资料明细按50条分页，日过程可导出。四岸已按用户提供的GCJ-02坐标近似转换至WGS84进入地图；原坐标和K码在“模型资料 → 空间与站网 → 站点档案”保存。

“湖位多站对照”可查看主站与四岸原始水位、同日差和共同参考日涨落。用户已确认五站采用同一高程基准且零点已统一；成果页“四岸核对”提供绝对湖位残差及逐站偏差、MAE、RMSE，默认按五站共同有效日评价并剔除初始化日，可切换各站有效日和导出。原值不再平移，新增评价不自动参与率定或覆盖冻结主站指标。详见随附《五站统一基准与绝对湖位评价-20261026.md》。

## 历史模拟

打开“历史模拟”，选择开始日期、结束日期和可选成果名称即可计算。后台自动绑定标准方案、兼容气象输入及固定参数，从2023年连续预热。可选日期上限由实际驱动覆盖决定。

“计算成果”默认打开选定的标准成果；其他业务计算在“计算记录”查看。过程日期与评价年份分别选择，切换评价年份不会裁剪过程图。日过程、逐时数据及完整末状态均可导出。

## 参数率定与模型状态

“参数率定”默认查看标准参数及历史评价。“新建率定”可选择杜加产汇流参数或湖泊蒸发系数；既定阶段自动衔接，计算可停止，成功成果可保存为候选参数。人工试调、计算预算和敏感性分析在高级设置中。保存或运行候选不会替换日常标准方案。

“模型状态”提供过程查询、状态分布和状态库。单元状态包含雪水当量、雪层液水、三层土壤含水量、自由水、产流面积比例和冰川调蓄，并提供分区流量、汇流储水及湖泊水量。可查询预热期与逐小时值；日状态取日末、流量取日均、通量取日累计。

状态分布对应真实保存时刻，不是可直接续算的完整状态。状态库中的完整末状态经模型、输入、空间、参数和观测身份检查后，才能从下一小时续算；不兼容的旧状态保留查看和导出。

## 导入资料

“模型资料 → 观测资料”提供标准表格模板。填写data工作表后直接导入，系统检查通过即入库。同一来源和内容不重复导入，修订内容保存新版本，普通流程不要求再次确认覆盖。

原格式Excel在观测资料的折叠入口导入。NetCDF在“气象驱动”接入，自动校验并沿用冻结的单位、时区及湖面降水转换。后续时段可与现有驱动衔接；重叠数值不同或中间缺测时停止处理并保留原文件，不静默覆盖历史。点观测不会替代全流域气象输入。JSON及后续API适配见《数据接入接口-v1》。

## 备份与迁移

“系统管理”负责工作区、运行状态、备份恢复和高级维护。使用“备份并下载”保存SQLite资料、来源快照、输入、用户成果和状态；恢复时先读取清单，确认后校验并写入新目录，重启采用恢复工作区。升级和卸载保留工作区。

## 使用范围

当前版本提供历史模拟，数据接入接口已预留，未启动外部数据轮询。超出气象覆盖的日期不能计算。湖位按观测窗口首值条件起算，主要河流中仅杜加具有流量约束；冰雪、湖面蒸发和湖盆关系尚缺独立过程观测。固定方案、结果与适用假设见《色林错标准方案与结果-v0.8.md》。

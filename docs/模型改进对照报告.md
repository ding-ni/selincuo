# 色林错模型改进与真实资料对照报告（v0.5.0）

本轮已经完成地图无底框标注、可选择的分水源汇流、连续湖泊水当量状态、逐月水量账、率定轨迹及局部敏感性与人工试调闭环。数值正确与水文适用性分别评价。本轮没有证据证明单一方案已同时满足杜加径流和全湖水位要求，不能作为已定型的未来预报模型。

## 数据与对照条件

37个月真实ERA5-Land原始文件已齐全（2022年12月至2025年12月）。输入 INPUT-967613234ca58f1c6cfb44e2，正式历史为北京时间2023-01-01 00:00至2026-01-01 00:00，共26,305个小时末时次、1096个完整日。2023统一预热；搜索、敏感性扰动选择及参考方案比较只看2024，2025留出评价。2026气象未提供，不生成2026或未来预报曲线。

原始8站、33来源、59,119条观测保留。空间版本SPATIAL-1e6a229e51f0da4f1ffd，30个高程带单元、535个气象格网；杜加是扎加内部控制区，避免重复计入入湖来水。

新旧汇流采用完全相同输入、观测快照、旧版冻结初始参数和随机种子42，各给240次产汇流评价预算，仅搜索KC、WM、B、SM、KI、KG、tauHours。新增壤中调蓄48h、地下退水720h固定；每种结构再独立冻结流域参数率定湖面蒸发系数，最多60次。两次湖泊搜索均实际25次达到当前停止判据，但系数都在1.5上界；这不是物理最优的证据。

平衡目标为0.5×(1−NSE)+0.25×(1−log1p流量NSE)+0.25×|PBIAS|/100。原汇流控制的旧指标在1e-8容差内复现，结构对照具有连续性。

## 方案取舍

在相同搜索预算下，2024平衡流量目标原汇流0.94650、分水源0.96022，原汇流略低；不能因分水源2025流量表现较好，反过来宣称它赢得2024搜索。两个产汇流搜索均预算耗尽，未收敛，该微小差异不能证明某结构普遍更优。

湖位是主要业务对象。预先实施的两组同参数控制与两组分步率定成果中，2024湖位RMSE最小的是“分水源汇流＋相同冻结参数”（0.15716m）。将其命名为“完整历史 · 湖位参考方案（2024比较，非业务定型）”供大屏回放；它沿用初轮陆面冰雪参数，新增记忆时间只是概念初值。原成果和本轮所有试验均保留。

这不是全局最优参数选择。后续KC单项试调虽使2024湖位RMSE降至约0.0679m，却使杜加流量PBIAS恶化至约−38.11%，因此保留为冲突诊断，不直接替换湖位参考。没有按2025评分选择此试调或参考方案。

## 对湖泊问题的判断

1. **单站流量与全湖水位不能互相替代。** 新分水源试验2025杜加NSE约0.702、总量偏差约−1.62%，但湖位RMSE增至0.1771m。杜加只约束内部控制区，全湖其余分区的降水、蒸散和参数移用仍可能有偏。不能把杜加参数直接解释为全流域已经验证。
2. **新安江仍是待验证的概念底座。** 蓄满产流结构在高寒、较干旱流域能否表达空间异质性，需要分区水量及观测约束；水量守恒只说明数值账目一致，不证明饱和产流机制、冰雪参数或汇流时间已经被资料识别。暂不凭少量资料加入冻土、额外地下水交换或更多自由参数。
3. **退水仍有问题。** 新分水源率定的2024/2025 log1p流量NSE约−1.859/−0.573，仍差于对应对数均值基准。普通NSE和年匹配总量较好，不能说明低流量和退水过程已正确。
4. **蒸发系数边界说明存在补偿风险。** 两种结构都希望湖面系数达到1.5上界，缺实测湖面蒸发时不能把它认定为真实蒸发率，也不继续扩大允许范围去抵消来水偏差。KC增加20%试验表明陆面耗水与湖位有强耦合，湖位好看可能来自低估流域来水。
5. **湖泊收支需要全年账和窗口湖位两条线。** 全年相对水当量蓄水连续累计并支持续算；条件湖位只在有可靠起点的窗口演算。冰期仍使用统一蒸发能力换算，没有湖冰热力、冰面蒸发/升华和冰膨胀模型。全年水当量图只是当前假设下的季节账，不能作为冰期真实水面高程。
6. **定面积和零净交换是资料约束下的首版假设。** 没有水位—面积/容积关系、湖面蒸发及冰封解冻日期，暂不输出动态面积或绝对库容。窗口残差不能直接当作实测地下水、湖底渗漏或外流。

## 湖位窗口残差

残差=观测蓄水变化−入湖水量−湖面降水＋湖面蒸发。负值表示按当前模型需要降低净入水或增加净失水才能闭合；不能识别具体成因。以日均水位近似日中水位，端点半权重，独立于严格逐时守恒验收。

## 调试与可复算

“计算成果 → 模型诊断”可切换年份检查逐月陆面降水、冰体外部供水、实际蒸散、单元与汇流蓄水、全湖来水、湖面降水和蒸发，查看全年水当量、窗口残差和率定轨迹。

局部敏感性覆盖KC、融雪/融冰度日因子、河道/壤中/地下调蓄和湖面系数，通常±20%，受允许范围约束，边界重复值跳过。仅比较2024响应；前端按参数分组，流量目标与湖位米值不合成为统一排名。它不证明参数唯一、没有交互，也不自动应用参数。已通过界面将KC扰动带入人工试调并保存真实三年成果，未覆盖参数库。

原汇流与分水源分支均可选择。源调蓄、雪水当量和连续湖泊蓄水均纳入状态；旧模型状态禁止跨版本强行续算。恢复旧方案会恢复其汇流结构。源码脚本 scripts/run_model_improvement.py 和 scripts/verify_model_improvement.py 可按已有报告任务ID继续核查，避免重复创建同一试验。

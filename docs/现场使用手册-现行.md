# 色林错现场使用手册（0.10.0整改版）

本手册对应0.10.0整改版（2026-10-27）。最终来源和评价初始化日修复已部署，8882服务为0.10.0，167项后端及31项前端检查通过。final2便携及实际隔离新装各18项、安装程序额外归档/冻结观测严格复算和离线八页补验均通过。本机隔离验收不等于独立无开发环境机器或全部整改完成。普通发行包与[外部发行收据](evidence/v0.10.0/release-receipt-v0.10.0.json)成套交付核验；现场核对实际版本、工作区、默认身份和文件摘要。首轮及final轮失败补验保留，不作为final2证明。

## 1. 默认与日常工作

打开已验收的0.10程序或业务服务即可查看受保护历史修订2的2024—2025冻结成果，无需先率定。核对程序版本、工作区、默认发布、当前成果与日期。湖位默认为窗口初始化，2024/2025 RMSE约0.06925/0.06523米；固定锚点连续精度必须另列。

业务模式查询总览、观测、历史模拟、成果与更新；专家模式增加方案研究和状态空间诊断。网址保存成果/日期/模式；研究候选跨页仍是候选。资料共同覆盖、成果计算/展示覆盖、最后合格观测日分别显示，缺测不是零。

监测应用筛选后查看图表、质量、原始分页和导出；失败时页面保留并标明上次成功结果。主站为工作基准，四岸原值与统计候选分开；统一零点结论已撤回。历史模拟先看只读运行计划：同冻结身份且已有覆盖可复用；其他情况具体核验或保守重算。自动兼容延伸预览尚未交付，专家完整状态续算另行严格核验。

旧成果湖泊日收支只统计窗口应用小时。空值不等于没有河流来水，部分日不等于完整日；不要将其与连续全年量直接相减。看图缩放不会改变年度评分。

## 2. 本批共同日期归档

专家模式进入成果中心，选择当前发布基准与两套成功成果，提交共同日期评价。后端读取真实冻结日值、排除初始化日，保存配对CSV和报告；完成后归档表自动更新，也可在任务中心下载完整产物。0.10final2实际安装已核验此流程、下载摘要与拒绝伪造分数；客户端不得上传分数、checks或强制通过。0.9安装不自动获得该入口。

归档成功只表示文件/数据库归档完成。窗口与连续、不同质量规则、不同锚点、冲突观测、缺共同样本或缺连续基准血缘会显示not-comparable。不可比报告可追溯，但不能给候选排名或发布资格。数据不全时不可变修订关联显示incomplete及原因。

初态稳定、水量、参数范围、输入来源、完整逐时产物和严格续算的正式诊断reader仍未接通，诊断unknown不是通过。当前默认是窗口成果，对应连续复现血缘尚未核验。业务capability中arbitraryRevisionRuntimeAvailable保持false，新发布禁止。

## 3. 不可变发布身份与运行请求

0.10按发布修订派发的运行计划、提交和排队执行携带expectedReleaseId。如果期间默认发布变化，必须刷新计划，不能用旧上下文继续运行。服务端从冻结修订准备实际参数、空间、输入与观测，不使用用户浏览的可变研究模板；输入延伸须验证真实历史前缀，数值实现变化保留真实新身份。

这些已部署约束和测试不表示任意新修订已具备业务派发完整证明。当前仍保持任意runtime能力false与新发布禁止；保存候选、收藏或归档均不会改默认。

首轮安装补验发现，旧默认观测快照有33项来源，干净种子省略了一份没有观测值的26KB站点位置表。数值相同但来源清单不同会改变完整SHA，严格复算拒绝是正确的。final2已携带真实冻结快照与33项来源，以成果ID、文件和内容摘要核验；安装EXE使用原6909…88e快照，2025湖位、杜加、总来水日过程与原成果最大差均0。原配置、默认成果及发布指针未改，这项来源修复不代表候选精度提高。

已完成独立E3：同一新控制域的1597单元与31组，仅比较有效驱动在非线性计算前后聚合。真实输入、参数、初态、汇流、湖面与锚点一致。31组不是旧30方案。

## 5. 状态、缓存、任务和恢复

状态使用成果自身空间与标签。日状态取日末、流量日均、通量日累计；历史帧只查看，完整检查点才可能续算。500米是垂直高程分带。未核实区约2340.743平方公里单列，不补零不当实际入湖；杜加只作为扎加一次。

0.10已部署有界查询缓存，减少反复解析成果/时间轴；真实1597空间帧与731日日过程对照旧版逐值相同。首次元数据/帧/单元两年过程实测6.911/1.125/5.464秒，后续5次p95为0.376/0.379/0.552秒。首次过程已经共享元数据/时间轴缓存且OS缓存未清，不是冷服务首查；5.464秒仍超约2秒目标。50毫秒RSS采样最大154.26MiB不是瞬时峰值或500MiB限额认证。冻结Zarr chunk不得脱离manifest就地修改，缓存不是任意篡改扫描器。

任务中心查看阶段、进度、心跳和产物。计算/率定/大导出/备份/恢复进入后台重任务；未完成文件不能下载为成功产物。恢复先预览，再在独立目录校验，完成后切换隔离指针并重启，原工作区保留。0.9已验的15GB异步恢复使用旧完整备份硬链接fixture，非重做备份、非全部现场升级路径。

# 色林错现场使用手册（0.12.0源码版）

双击“启动平台.bat”，核验后打开8882。原8879及已有EXE属于其原版本。本机工作区由 `config/active-workspace.json` 指定，后端统一提供前端；关闭浏览器不影响后台任务。

## 湖情总览

模拟回放默认打开综合方案的连续成果。主站湖位、相邻完整日涨落、入湖合计流量和模型日降水与地图、曲线游标整帧同步。底部可以播放、步进、拖动、选日期和调速度。等待保留原完整画面；失败可重试，无观测与驱动缺测分别显示。

左侧查看流域雨情、实测对照和四岸观测，中央地图保持真实比例，右侧查看四河、湖周直接来水与湖泊收支。普通与全屏保留相同信息；主要桌面保持单屏，真正较小窗口允许滚动。主题和叠加要素分别控制。模型降水含面积聚合及湖面订正，地形上的气象格网显示再分析原值，点击可查当日数值，两者分开标识。回放使用全时段统一色阶，地形来自已登记DEM。四岸显示所选日的原基准日值；区分该时段无记录、当日无有效日值和读取失败。站点监测只用真实观测，资料目录另显示最近日期。

每张过程图可独立滚轮缩放横轴、拖动平移、框选横纵轴、复原和放大。底部回放日期继续控制垂线，图上常驻日期、模拟及实测读数和单位，缺测不插值。日期落在局部视窗之外时保留该图范围，点击“定位日期”移动到所选日。隐藏曲线不影响日期垂线。降水主题直接显示0.1°再分析源格网，点击查看格点原值；业务摘要仍显示实际模型采用的面积加权雨量。

切换至“站点监测”后，左侧显示主站近期湖位过程、涨落和读数，右侧以独立卡片展示四岸。近期过程默认90日，可切换30或180日；各岸使用本站原基准、分别绘图。所选日缺测时显示缺测，并给出该日之前最近一次有效实测及日期；曲线在缺测处断开，不引用未来观测。地图优先显示湖泊和流域名称；测站位置保持真实坐标，站名通过引线避让主体名称。测站的显示开关不改变主体名称位置。

## 监测资料

选择站点、变量或时段后，页面自动查询并显示对应过程线和表格，也可导出。原始观测和整编日值分别保留，统计规则在详情；资料时段以页面实际显示为准。四岸各自覆盖不限制主站。

四岸保留原始值和整编日值；偏移候选或相对分析不可用时仍可查观测。偏移/零点分析首次展开才计算，单站失败只影响该站。四岸基准待核，以本站资料和相对变化分析，不参与统一绝对湖位率定。需要北、东、南、西站的零点高程、水准基准、联测来源和设备变更日期，不能以统计拟合代替测量。

## 模型方案与率定

顶部以当前打开的方案名称为主，旁边标明“当前采用”“我的方案”或“新方案”，右侧显示保存状态。直接点击 **资料与时段 → 参数与范围 → 运行率定 → 结果评价** 切换步骤。

点击“新建方案”可建立自己的独立方案；“复制方案”沿用正在查看的设置建立副本。填写方案名称或修改设置后，统一点击“保存方案”。后台保留各次保存的设置，管理列表的“保存历史”可查看保存次数；日常操作不需要选择内部修订号。新建或复制不会改变当前正式成果；需要切换首页成果时，在新计算完成后点击“保存并采用”。

“管理方案”集中查看已保存方案，也可在“开发试验”查看以前的试验。勾选旧方案，点击“移入回收站（含关联结果）”，核对后确认，方案各次保存的设置和关联计算结果一并回收。在同一窗口的“回收站”可“恢复方案与结果”；本次回收前已单独回收的结果保持原回收状态。

需要移走本地文件时，在平台回收站勾选方案，点击“移入Windows回收站”，核对实际文件目录、数量、大小及关联对象后确认。只处理可独占的成果与导出目录，使用Windows回收服务并核验可恢复条目；原始观测、共享气象、空间、共享配置继续保留。当前采用或仍在使用的对象会在预览中列出并保留。平台保留方案、参数和任务记录，以便恢复关联；这不会立即释放磁盘空间，是否清空系统回收站由用户决定。恢复时先在Windows回收站还原全部目录到原位置，再在平台恢复方案和结果。操作中断后可按原选择继续，已成功移走的目录不会重复处理。

1. 在“资料与时段”查看预热起日、杜加流量和主站湖位各自的率定期、检验期及有效资料数。湖位起算值用于初始化，率定与检验使用各自的观测时段。“单独重做一个阶段”可选择只重做水文或湖泊率定。
2. 在“参数与范围”按陆面产流、积雪与冰川、汇流和湖泊查看参数。可选择参与水文率定的参数并修改初值、上下界；22项水文参数可参与搜索，湖面蒸发系数在固定来水后确定。初值和结果值分别显示；只有点击“以上次结果为初值”才会把结果改为新的率定初值。
3. 在“运行率定”查看流量和湖位目标权重、搜索规模及多起点编号，点击“开始率定”。修改设置后会先保存为方案新修订，再按该修订提交；不修改时使用已绑定的原始配置。计算期间可查看进度、停止并保存进度，停止后可从该任务的结果页选择“继续已保存的率定”。
4. 在“结果评价”查看流量和湖位过程、分期指标、实际搜索记录及参数变化。点击“保存并采用”可将结果设为当前成果，也可在开始前主动选择“完成后采用”。“人工微调并试算”从该结果建立调整方案；只改湖泊系数时复用相同条件下的来水，改水文参数则重新计算来水。

页面所示的初值、范围、时段、目标、种子和预算以方案绑定的可执行配置为准。初值平时简短显示，点击编辑时显示完整精度；只查看或切换步骤不会改动原值。“计算记录”可打开以前的任务，点击“本次设置”读取该任务关联的设置；成功结果可导出完整设置与记录。旧版冻结复现记录和兼容接口继续保留，日常重新率定使用普通“开始率定”。

当前正式方案为“色林错连续模拟方案”，采用暖雨订正驱动及其完整率定成果，已绑定当次可执行配置；打开率定页可查看并调整这份配置。原驱动完整率定、以前的方案和结果仍在历史记录中，查看历史结果不会改变当前采用。两套方案的比较及分期指标见[双驱动交付记录](双驱动完整率定与正式方案-20261030.md)。

陆域采用方案中登记的共享参数，各单元保留自己的气象、高程、面积和冰川覆盖。分期结果与全部资料定参结果分别保存；查看检验指标时结合该任务实际使用的资料理解。参数来源可在结果详情查看，完整审计见[参数审计与传递](新安江参数审计与传递-20261028.md)。

“保存方案”可在不开始计算时保存已修改的设置，未保存的修改只留在当前页面。当前采用和正在计算的对象受保护。

当前0.12.0为源码版，尚未制作新安装包。未来制作安装包时需另行确定并核验随包资料和资源清单，开发测试数据库及实验方案不默认打包。换电脑时需另行备份并迁移工作区，不能假定仅安装程序就包含本机用户方案。

已准备安装版的快捷方式启动与页面随关即退逻辑：快捷方式读取配置端口启动服务并打开网页，关闭最后一个平台页面后约5秒退出，刷新和其他仍打开的页面不触发退出；若有计算先停止并保留进度再退出。浏览器异常退出时通过会话超时回收服务。源码开发入口8882继续常驻，便于调试。本轮仅核验源码和独立浏览器会话，EXE及安装包待下一轮用户确认后构建验收。

## 历史模拟

选择方案、参数和起止日期，查看资料与起算核对。相同条件已有完整成果可直接查看，也可明确重算。新气象可以用于新计算，不改写旧成果。

默认选择后台当前采用的方案与成果，预热、起算和可模拟时段按方案与资料覆盖显示。各阶段及分年结果可在率定成果详情查看；查看历史结果不会切换采用方案。

## 成果与过程状态

成果中心默认显示“当前成果”，对应后台采用关系。“历史成果”查看其他已保存成果，“试算与计算”查看试算及未保存计算，可按名称或编号检索、命名保存、比较、导出或移入回收站。查看历史成果不会改变首页采用的成果；失败、停止和中断的任务保留状态，不提供不存在的导出。

方案、参数和成果回收站统一提供“移入Windows回收站”，先预览再确认，使用和方案管理相同的文件处理与引用保护规则。日常界面取消永久删除及清空入口；旧永久删除接口仅作既有兼容保留，本轮操作不会调用。共享输入和观测不随成果回收移走。查看成果不改变方案采用参数。

比较需匹配变量、空间和日值含义，窗口与连续指标不能混用。条件详情保留当次输入、参数、初始化和观测身份。

过程与状态按成果、变量、时刻查询；可用流域区域、高程带和地表类型联动筛选，再选择计算单元或输入编号检索。选中对象后地图定位并显示真实边界，未纳入计算的背景不列为计算区域。色阶可使用成果完整时段、当前时刻或自定范围。流量为日均、通量为日累计，日末状态显示对应日期，导出保留真实时刻。续算使用状态库中的完整末状态，并核对参数、空间、模型实现和已算时段的气象资料。

## 资料更新与问题定位

在“资料更新 → 观测资料”选择监测系统导出的 `.xls` 或 `.xlsx`，可一次选择多个水位、流量和雨量文件。页面按文件名和工作表识别站点、要素、年度日表、逐次资料及四岸；无法识别站点时可在文件旁选择。点击“检查资料”，核对站点、要素、时段和新增、更新、相同、缺测数量，按需展开查看已有时次变化与需核对的观测值，然后点击“确认更新”。其他格式可展开“其他格式导入”。

相同时次同值跳过，新时次追加，变更值写入新记录，原文件和历史值保留；同名增量文件不会覆盖此前时段，表内空白也不会抹掉已有有效值。未确认覆盖的稀疏雨量缺行仍按缺测处理。更新后站点目录和日值随之刷新；有计算任务运行时须待任务结束再确认入库。

气象选择补充日期或更新至产品可用日期，后台核验并复用完整月份和请求，连接下载、整理、校验和登记；NC是内部格式。CDS授权仅在本机配置，不展示密钥。认证可用不代表全部年份已下载，范围以任务结果和资料覆盖为准。停止保留已完成月份、分段及请求；恢复时由平台复用，不清空下载目录。关闭网页可继续下载，正在补数时请保持源码服务运行。

原驱动和站点暖雨订正驱动已分别保存、完整率定和比较。当前采用暖雨方案：陆域和湖面使用同一液态暖雨处理口径，依据符合条件的站点季节雨量按距离平滑传播，不用液态雨资料缩减冬季总降水，也不叠加旧湖面全年倍率。各输入版本的规则可在资料详情查看，早期固定参数对照保留为历史记录。

当前31组计算结构使用四河和严格地形判定的湖周，约2061.29 km²未定范围仅为地图背景，不参与本轮产流和入湖统计。地图保留实际空间比例与0.1°气象支持面。

完整运行资料外置，Git配置不能替代数据包。缺少内置连续成果时明确提示，观测仍可独立查询。任务中心查看进度、取消和失败原因；停止保留已有产物。每次源码启动日志保存在 `build/源码服务-日期时间-批次号`，不要为浏览器问题清空工作区。

# 色林错现场使用手册（0.12.0源码版）

双击“启动平台.bat”，核验后打开8882。原8879及已有EXE属于其原版本。本机工作区由 `config/active-workspace.json` 指定，后端统一提供前端；关闭浏览器不影响后台任务。

## 湖情总览

模拟回放默认打开综合方案的连续成果。主站湖位、相邻完整日涨落、入湖合计流量和模型日降水与地图、曲线游标整帧同步。底部可以播放、步进、拖动、选日期和调速度。等待保留原完整画面；失败可重试，无观测与驱动缺测分别显示。

左侧查看流域雨情、实测对照和四岸观测，中央地图保持真实比例，右侧查看四河、湖周直接来水与湖泊收支。普通与全屏保留相同信息；主要桌面保持单屏，真正较小窗口允许滚动。主题和叠加要素分别控制。模型降水含面积聚合及湖面订正，地形上的气象格网显示再分析原值，点击可查当日数值，两者分开标识。回放使用全时段统一色阶，地形来自已登记DEM。四岸显示所选日的原基准日值；区分该时段无记录、当日无有效日值和读取失败。站点监测只用真实观测，资料目录另显示最近日期。

## 监测资料

选择站点、变量、时段后查看过程线、表格并导出。原始观测和整编日值分别保留，统计规则在详情。主站有效湖位始于2021-04-23，2021/2022已有247/269个有效日；当前最后合格整编日2026-09-13，目录最后记录不等于最后有效日。四岸各自覆盖不限制主站。

四岸保留原始值和整编日值；偏移候选或相对分析不可用时仍可查观测。偏移/零点分析首次展开才计算，单站失败只影响该站。四岸基准待核，以本站资料和相对变化分析，不参与统一绝对湖位率定。需要北、东、南、西站的零点高程、水准基准、联测来源和设备变更日期，不能以统计拟合代替测量。

## 模型方案与率定

内置方案已配置完整，修改前复制。填写方案名和计算设置，参数按产流、积雪、冰川、汇流、湖泊及真实分区查看和编辑。人工调参后可直接试算，无需先自动率定。

模拟较早时段时，后台自动核对预热及可用主站日值并显示实际起算依据；需要人工指定时，在高级湖位起算设置填写整点、水位和来源。日值按12时代表的起算不等于瞬时实测，起算当天不当作完整湖位日。

新建方案默认“杜加流量率定，湖位仅评价、不参与本次参数排序”。25项完整参数都有来源和先验范围；22项可按需参与流量搜索，分陆面、雪冰和汇流阶段，1—4个起点共享每阶段总预算。每阶段次数包含基线、局部响应诊断和全部起点，预算耗尽不等于收敛。两个裸冰升华参数和湖面系数不进入杜加流量目标；缺独立雪冰资料时，能拟合流量也不表示雪冰过程已验证。2025/26曾参与开发，不能称未触碰的独立外部验证。

参数在流域内可按原分区、杜加共享或面积尺度对照使用。复制旧方案后明确建立共享基准，才把杜加值迁入共用参数并清除覆盖；不会自动改旧方案。面积尺度仅是等形等流速假设，详情可查每区实际值、来源和单元引用。可选湖泊/联合研究单独注明湖位是否进入目标，不能混称纯流量率定。完整审计见[参数审计与传递](新安江参数审计与传递-20261028.md)。

选中成功成果后保存参数，保存其实际完整参数，再由方案采用。“设为率定初值”是独立动作，采用不暗改初值。旧成果不随方案编辑变化。

新建或复制方案后，点击“保存方案”，设置即保存在当前本机工作区，重新打开平台仍可使用。未保存的修改只在当前编辑页面保留，切换页面或重启前请先保存。方案可移入回收站并恢复，包括内置方案；已有成果保留，正在排队或计算的方案暂不能回收。“方案与参数回收站”也可回收或恢复已保存参数；回收只移出日常选择列表，已采用方案和历史成果仍保留原参数。需要再次显式选择该参数时先恢复。

当前0.12.0为源码版，尚未制作新安装包。未来制作安装包时需另行确定并核验随包资料和资源清单，开发测试数据库及实验方案不默认打包。换电脑时需另行备份并迁移工作区，不能假定仅安装程序就包含本机用户方案。

## 历史模拟

选择方案、参数和起止日期，查看资料与起算核对。相同条件已有完整成果可直接查看，也可明确重算。新气象可以用于新计算，不改写旧成果。

内置陆面预热始于2023-01-01，湖位锚点2023-04-20 12时，完整湖位从2023-04-21起；当前成果完整日至2026-10-20。单独结束于锚点前的请求会提示调整，不能填造初始化之前的湖位。2020—2022气象已补齐登记，统一资料库完整日为2019-12-31—2026-10-20。2021年实际业务试算及续算已通过，湖位最早从2021-04-23日值的12时代表时刻起算，首完整日为2021-04-24；用户无须选择内部输入产品。第三轮另存2021以来的A0/A1/A2实际对照，原采用2023锚成果保留；新方案和新成果独立保存，未自动覆盖原采用绑定。

## 成果与过程状态

成果中心以已保存成果为主，可打开、改名保存、比较、导出、回收和恢复，临时计算另列。旧自动收藏可明确选择“显示在湖情总览”，只有用户明确保存且展示能力完整的结果才进入首页。失败、停止和中断的任务可在临时页和回收站管理，不提供不存在的导出。

方案、参数和成果回收站提供“彻底删除”：先预览数量、独占空间与依赖，再一次确认永久释放。受采用、活动任务或状态强引用保护的对象不能删除；共享气象、空间、原始观测不随成果删除。失败可按原操作记录重试。这与可恢复的平台回收、Windows回收站是不同动作，不自动清空任何真实回收站。共享输入和观测不会随成果回收而删除，内置成果和仍在使用的资源受保护。查看成果不改变方案采用参数。

比较需匹配变量、空间和日值含义，窗口与连续指标不能混用。条件详情保留当次输入、参数、初始化和观测身份。

过程与状态按成果、变量、时刻和区域/高程查询，编号在详情保留。选中真实单元、分区、河流或湖泊自动定位，全流域可恢复视角；微小片区只加位置圈，不扩大真实几何。默认色阶从该成果完整保存时段计算并复用，也可锁定当前或自定范围。其他排水范围在详情展开，仍保留其产流和储水记录。流量为日均、通量为日累计，日末状态显示对应日期，导出保留真实时刻。地图用于查看，续算需要完整末状态，并核对参数、空间、模型实现、计算步长和已算时段的气象资料；新评价观测可以更新，不重新设定湖位起点。

## 资料更新与问题定位

观测上传先预览字段、日期、异常和重复冲突，再按选择增量入库，保留原件及来源，不复制整库。完成后可前往模拟或率定。

气象选择补充日期或更新至产品可用日期，后台核验并复用完整月份和请求，连接下载、整理、校验和登记；NC是内部格式。CDS授权仅在本机配置，不展示密钥。认证可用不代表全部年份已下载，范围以任务结果和资料覆盖为准。停止保留已完成月份、分段及请求；恢复时由平台复用，不清空下载目录。关闭网页可继续下载，正在补数时请保持源码服务运行。

主站2024年雨量用于湖面0.53367比例订正；其余点雨量尚未融合陆域。站点日界、完整性、降雪漏测和空间代表性保留来源限制。

90米地形用于本轮残余排水复核；当前31组水文结构和0.1°气象支持面保留，不等于90米河道水动力求解。尚未确定出口的2247.523850 km²不并入入湖合计，位置和所需资料见空间核查。

完整运行资料外置，Git配置不能替代数据包。缺少内置连续成果时明确提示，观测仍可独立查询。任务中心查看进度、取消和失败原因；停止保留已有产物。每次源码启动日志保存在 `build/源码服务-日期时间-批次号`，不要为浏览器问题清空工作区。

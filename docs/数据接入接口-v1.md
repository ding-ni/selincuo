# 数据接入接口 v1

当前采用文件导入，服务不主动请求外部URL。后续单位提供下载网址或API后，只需增加该来源的读取适配器，将字段转换到本接口；模型计算层继续读取版本化输入。

## 现有导入

“工作区与系统 → 资料更新与维护 → 标准表格导入”下载模板，在 `data` 工作表填入记录后直接导入。UTF-8 CSV也可使用相同表头。系统统一检查后入库，不设重复人工登记流程；错误显示具体行号。

必要表头：`station, variable, time, value, unit, step`。

可选表头：`periodStart, periodEnd, quality`。

- 站号：SLC、SLC-E、SLC-S、SLC-W、SLC-N、DUJA、BLQ、115DB。
- 变量：precipitation、temperature、evaporation、flow、level、area、snowWaterEquivalent。
- 时间尺度：day（日标记00:00）、hour（整小时结束时刻）、irregular（保留分钟/秒）。
- 质量：valid、qualified、missing、ice_or_stopped。缺测、停测可保留原始文字。
- 单位：降水/蒸发/雪水当量 mm或m；气温degC或K；流量m3/s或L/s；水位m或cm；面积km2或m2。

日值代表当地完整日；小时值代表结束于time的前一小时，零点计入前一天。不规则降水、蒸发增量必须提供统计起止。缺失间隔不推断为零；原有稀疏雨量的有效观测覆盖规则继续由原适配器维护。

## API与转换

- `GET /api/model/data-contract`：格式和预留的未来格网字段。
- `GET /api/model/data-template`：空白Excel模板，不含演示观测。
- `PUT /api/model/upload?format=exchange&filename=文件名`：上传xlsx或csv至本工作区。
- `POST /api/model/data-import-file`：导入上传文件，支持固定字段映射。
- `POST /api/model/data-import`：按相同契约导入JSON记录。

JSON示例：

```json
{
  "schemaVersion": 1,
  "projectId": "selinco",
  "sourceKey": "主站日水位-2026",
  "timeZone": "Asia/Shanghai",
  "records": [
    {"station":"SLC","variable":"level","time":"2026-07-01T00:00:00","value":4544.2,"unit":"m","step":"day"}
  ]
}
```

示例数值仅用于接口说明，未写入资料库。文件请求用 `filename` 替换 `records`，可增加 `sheet:"data"`、`mapping:{"time":"测报时间","value":"水位"}` 和 `defaults:{"station":"SLC","variable":"level","unit":"m","step":"day"}`。单位、时间定义和字段映射由来源适配器固定配置。

同一sourceKey表示同一份完整资料快照。内容不变重复导入不增加记录；修改后形成新版本，旧记录保留。重新上传旧文件不会将当前版本回退。按年或按批追加应使用独立sourceKey；修订同一年度文件沿用原sourceKey。

API当前仍仅允许本机访问，与桌面软件一致。未来外部服务由本机读取适配器接入，无须把桌面服务直接暴露到互联网。外部URL、鉴权方式和字段映射以后配置，当前没有虚构地址或启动轮询。

## 模型驱动边界

站点资料用于观测和核对，不自动替换0.1°全流域气象驱动。未来格网资料另按空间版本、有效时间、起报时间、预报时效、成员和单位组装完整输入产品，再进入同一模型；缺少降水、气温或蒸发能力不直接补零。湖面降水订正是明确的独立输入转换版本，与站点导入分开管理。

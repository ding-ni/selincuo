# 色林错模型结构复核与调试功能（0.5.0）

本轮依据0.4.0实际问题改进：杜加2025年径流量偏低约26%，SM、KG达到下界，公共汇流时间达到上界，湖面蒸发系数达到上界。不能只扩大参数范围或用验证期挑选参数解决这些现象。

## 结构判断与实施

1. 保留半分布式新安江、雨雪划分、雪层融化与再冻结、固定边界冰川度日消融。冻土仍未加入。三层张力水、自由水和冰雪内核继续以原标量实现为数值对照。
2. 增加可选择的分水源汇流：RS与已有冰川调蓄出流直接进入河道；RI先经过壤中调蓄，RG先经过地下退水水库，然后统一经过河道线性水库与传播滞时。每个环节保存状态及独立水量账。原单库汇流保留用于对照。
3. 新增壤中调蓄48 h、地下退水720 h初值，均为明确登记的概念初值；本轮自动搜索仍只有7个既有产汇流参数，新增记忆参数先做局部敏感性诊断，不凭一站自由搜索全部参数。
4. 度日融雪来自既有SWE蓄水，不是额外外部水源；融冰和裸冰升华消耗未显式维护的固定冰川冰体质量，单独列冰体外部项。融水不能在总入湖径流以外再次相加。
5. 杜加仅控制扎加内部子区；全湖来水为四河加湖周，杜加不重复加入。子流域边界、面积、高程带和格网权重不因本轮模型改动而改变。
6. 对湖泊区分全年连续水当量相对蓄水与可靠观测窗口条件湖位。全年净收支连续累计并纳入状态续算，冰期不把水当量蓄水换算宣称为可靠水面高程。当前没有冰厚、冰上积雪和冻结膨胀过程。
7. 湖位仍在窗口起点以可靠观测初始化，随后不逐日纠偏。这属于给定起点的历史模拟。观测连续窗口不等于已独立识别的无冰期，需结合现场或遥感冰情核验。定面积、地下水净交换为零等假设保留并明确展示，不虚构库容曲线或地下水。

## 率定与调试

新增平衡目标：0.5×(1−NSE) + 0.25×(1−log1p流量NSE) + 0.25×|PBIAS|/100。保留原洪峰目标供对照。两种目标均只使用2024观测，2025及2026不参与搜索或敏感性排序。完整2023预热和完整2024评价均由后端校验，不能从2023中途起算冒充完整预热。

新增局部敏感性任务：每次只扰动一个参数，通常为±20%，受物理范围限制；计算全部历史过程但仅用2024响应排序。可将一个扰动带入人工试调，核对后显式运行，不自动覆盖已有参数或成果。该分析不证明参数唯一或最优，也不刻画参数交互。

结果页增加模型诊断，包含月度陆面降水、冰体外部供水、实际蒸散、单元蓄水变化、汇流蓄水变化、入湖来水、湖面降水和蒸发、湖泊净收支、率定目标与轨迹及敏感性明细。

湖位窗口未解释净入水按观测蓄水变化减去模型入湖与降水、加蒸发计算。日均水位按日中近似，端点采用半权重。它是资料与模型共同残差，不能直接解释为地下水；缺完整气象端点时不估算。严格数值守恒另用逐时闭合误差检验。

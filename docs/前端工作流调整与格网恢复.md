# v0.2.0：业务工作台与真实格网恢复

本次对照主平台最新 `SimulationView.vue`、`CalibrationView.vue`、`ResultWorkspace.vue`、`DailyResultPanel.vue`，保留成熟的操作关系，适配色林错连续冰雪产汇流及湖泊过程。

## 工作流调整

| 原平台可复用经验 | 色林错实现 |
|---|---|
| 固定计算条件与当前过程并排 | 左侧参数来源、输入、起止和执行；右侧过程评价、参数试调、计算准备 |
| 命名方案与命名参数分别管理 | 方案恢复输入/时段/参数；参数库可直接用于其他时段 |
| 人工试调和自动率定共用工作台 | 率定页切换；人工试调保留独立任务类型，参数按产流、冰雪、汇流、湖泊分组 |
| 成果可作为后续操作入口 | 采用参数、恢复条件、查看状态、继续计算、导出日/小时过程 |
| 历史成果列表与详情并排 | 按名称、日期、类型、分组过滤，区分保留成果、未完成和回收站 |
| 过程与评价分开查看 | 湖位、入湖来水、年度评价与收支、冻结参数、本次条件分别显示 |
| 比较前先核对边界 | 不同空间版本或无共同日期不叠加；不同输入版本明确提示条件差异 |
| 编辑选择可恢复 | 本机浏览器保存条件与参数草稿；成功成果始终使用冻结请求 |

色林错不引入南安溪洪水目录、业务数据库、实测资料或30 m河网。湖位优先，杜加作为内部控制断面，年度预热/率定/验证分工保持不变。数据不足的年度计算在提交前显示原因。

## 格网问题的核实结果

2026-10-22（北京时间）实际查询CDS，服务返回403与账户停用信息。通过页面提交的新下载任务同样在一次可用性检查后停止。当前账户无法提交或恢复远端任务，不能把缺失资料视为已补齐。

原始文件经实际读取：37个所需月份中10个月完整、27个月缺失。完整月份为2022-12、2023-01至04、2024-01及12、2025-10至12。2022-12为起算差分及北京时间转换缓冲。

下载器修复内容：

- 按原始文件内容核验每个变量和每个小时，错误文件名不影响覆盖判断；缺小时、缺变量不能判完成。
- 单月串行请求，任务身份持久化；可恢复同条件历史请求，包括可用的旧分组请求。
- 已完成结果分段传输；分段绑定请求身份、大小，并保存SHA256。损坏分段重传，不复用无摘要旧分段。
- 合并后实际读取NetCDF并检查完整月份，校验通过才作为完成文件登记。已有不完整原件保留，修复文件另存。
- 区分账户停用、认证、数据许可、队列配额、成本与网络失败；敏感链接和凭据不写入任务提示。
- 直连只作用于本次任务的网络会话，不改变系统代理或其他计算任务。
- 支持停止、保留远端任务与本地断点；重试由用户主动发起，不循环请求被停用账户。

## 恢复资料的操作

1. 联系 [ECMWF支持](https://support.ecmwf.int/) 恢复CDS账户，或在本机用户目录 `.cdsapirc` 配置另一已授权账户。不要向平台或聊天发送密钥。
2. 在“模型与资料”点击“继续补齐缺失月份”。也可上传已合法取得、相同范围与变量含义的ERA5-Land原始NetCDF，再核验覆盖。
3. 选择连续原始文件并登记真实输入。缺月不能补零；登记继续检查累计差分、时区、单位及空间覆盖。
4. 补齐后运行 `scripts/historical_workflow.py`，先基线，再2024分步率定和冻结条件下2025独立验证。

未将ERA5、ET0或其他分辨率产品静默替换为ERA5-Land。年度率定和验证仍待真实资料完整后开展。

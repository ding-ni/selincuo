## 冻结目标与参数

流量目标为 `0.50×(1−NSE) + 0.25×(1−logNSE) + 0.25×|PBIAS|/100`；低流量分项使用原数值内核的 `log(1+Q)`。湖位过程RMSE、累计趋势误差、季节涨幅误差及高点日期误差各占25%，尺度分别为0.1米、0.1米、0.1米及14日。完整双目标为流量目标与湖位目标各占50%。尺度用于无量纲化，不作为达到10厘米即停止的门限。

22项水文参数全部参与本轮搜索。两项裸冰升华参数在现有模块中不改变入湖流量，保留在后台诊断配置；常规参数表仅列22项水文参数和湖面蒸发系数。每个区域保留自己的气象、高程、面积和冰川覆盖，共享同一水文参数组。杜加包含在扎加内部，入湖合计只加扎加总量一次。

## 前端与实际运行一致性

普通“开始率定”读取方案绑定的不可变配置，直接提交配置摘要，不在浏览器中重拼历史请求。初值、范围、时期、目标、种子、预算与实际执行使用同一份配置；最终参数另存。修改设置保存为新修订，只有主动选择“以上次结果为初值”才替换初值。

[单独湖泊模式验收](evidence/单独湖泊率定配置验收-28a90b9d91.json)也已通过：湖泊初值在页面、修订及请求中一致，水文参数固定为采用结果，切回完整模式仍保留原始水文率定初值。原驱动正式任务在27016次评价处的[停止接续](evidence/完整率定停止接续-20261030.json)已实际验证，请求、种群和随机状态保持。

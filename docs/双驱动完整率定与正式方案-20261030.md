## 冻结目标与参数

流量目标为 `0.50×(1−NSE) + 0.25×(1−logNSE) + 0.25×|PBIAS|/100`；低流量分项使用原数值内核的 `log(1+Q)`。湖位过程RMSE、累计趋势误差、季节涨幅误差及高点日期误差各占25%，尺度分别为0.1米、0.1米、0.1米及14日。完整双目标为流量目标与湖位目标各占50%。尺度用于无量纲化，不作为达到10厘米即停止的门限。

22项水文参数全部参与本轮搜索。两项裸冰升华参数在现有模块中不改变入湖流量，保留在后台诊断配置；常规参数表仅列22项水文参数和湖面蒸发系数。每个区域保留自己的气象、高程、面积和冰川覆盖，共享同一水文参数组。杜加包含在扎加内部，入湖合计只加扎加总量一次。

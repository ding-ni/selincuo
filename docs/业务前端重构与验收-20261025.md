主导航统一为“湖情总览 → 监测资料 → 参数率定 → 历史模拟 → 计算成果 → 模型状态 → 模型资料 → 系统管理”。

| 页面 | 当前行为 |
|---|---|
| 湖情总览 | 中央地图、两侧湖位与来水、底部统一回放；浅深两色、全屏、导航收起、全流域与湖区适配。四河和湖周来水分开展示，杜加仅为内部控制断面。更多过程按需展开。 |
| 监测资料 | 站点实有要素与尺度、实际起止时间、全日期轴空值；首屏仅日过程，明细打开后服务端分页。降水柱图，水位和流量折线。查询取消旧请求，局部加载。 |
| 参数率定 | 默认标准参数工作副本；杜加产流→汇流自动顺序执行，湖泊蒸发系数单独维护。统一进度、停止、评价和候选保存；预算、人工试调与敏感性进入高级设置。 |

| 计算成果 | 明确选定的标准成果为默认入口，业务任务进入计算记录；内置与任务成果共用过程、评价、导出组件。过程日期与评价年份独立。 |
| 模型状态 | 过程查询、状态分布、状态库；成果、变量、时段、保存时刻与空间单元联动。8类单元状态、产流分量、汇流储水及湖泊水量均可查询。 |
| 模型资料 | 模型配置、观测资料、气象驱动、空间与站网；统一资料导入，校验通过后接入。后续气象延伸沿用冻结的湖面降水转换。 |

## 接口与统计口径

以下新接口均以 `/api/model/` 为前缀。旧观测、任务、成果接口继续兼容。

| 接口 | 主要参数与返回 |
|---|---|
| `observation-catalog` | 站点、坐标可用性、实有变量、原始尺度、有效时段、有效/总记录数。 |
| `observation-series` | `station, variable, start, end`；完整日期轴的日过程，缺测为 `null`。 |
| `observation-page` | `station, variable, step, start, end, page, pageSize`；`rows,total,page,pageSize`，默认每页50条。 |
| `result-capabilities` | `resultId`；成果覆盖、空间单元、变量目录、聚合口径及末状态能力。 |
| `result-series` | `resultId, variable, unit, start, end, step`；单元/分区/湖泊时段序列。`unit`为目录中实体的下标。 |
| `result-frame` | `resultId, variable, time`；指定真实保存时刻的空间值，明确标记 `completeCheckpoint=false`。不存在的时刻拒绝读取。 |
| `result-checkpoint` | `resultId`；完整末状态及当前模型实现兼容提示。 |
| `tasks`（提交） | 新增 `kind=calibration-workflow`；`target=duja` 自动衔接既定阶段，湖泊对象使用对应蒸发率定。沿用任务进度和停止接口。 |

目录、分页与日过程使用一致的来源修订规则。日过程按资料修订缓存，导入或修订后失效；同一冷查询合并计算。数据库增加站点、变量、时间联合索引；聚合不再静默截断原始记录数量。明细分页按观测时间及记录编号稳定排序。

小时模型资料按北京时间既定口径处理：每日 `(当日00时,次日00时]`；状态取次日00时的日末值，流量取完整24小时均值，通量取完整24小时累计。缺少完整小时的通量/流量不补零。状态单位为 mm（FR无量纲），流量为 m³/s，汇流与湖泊水量为 m³，湖位为 m。

只有完整末状态可以提交续算；真正运行时继续严格检查模型、输入、空间、参数和观测身份。空间帧没有完整传播队列，不能转换成续算状态。旧身份保留，不通过改写摘要接受旧状态。当前源码实现摘要变化后，不兼容旧末状态仍可查看和导出。没有绝对湖位锚点的时段保持空值，不从相对水量推造湖位。

# 正式业务前端调整

本轮调整前端业务呈现，数值模型、内置方案修订2、参数和选定历史成果保持不变。

## 日常业务

- 主导航保留湖情大屏、监测资料、历史模拟、计算成果、过程与状态、模型与资料、工作区与系统。
- 模型维护入口位于系统高级维护，主动打开后提供参数率定与诊断；返回普通业务成果页仍采用简洁视图。
- 监测页提供查询、日过程、明细分页与日资料导出。记录状态使用业务名称，来源信息按需展开。覆盖登记和停测区间编辑不再放在普通查询流程中。
- 查询结果绑定提交时的站点与变量，修改尚未提交的筛选条件不会把旧曲线标成新变量或新单位。
- 成果库包含内置最终成果及业务计算，普通视图不展示搜索轨迹、敏感性、参数触边、版本摘要或原始JSON。保留图表、评价、对比、导出、收藏、命名与状态入口。
- 模型资料默认展示标准方案、可用驱动、流域站网与只读参数。计算结构按需展开，不展示候选输入和空的自定义参数表。
- 工作区以资料导入、统计、备份恢复为主，不平铺数据库字典、库版本和运行路径。下载与空间重建进入高级维护。
- 帮助页集中提供使用指南、计算方法、观测处理、模型假设与适用范围。

## 大屏

去除反复出现的开发说明和未接入功能清单。保留历史回放、模拟与实测、日期、缺测、实际收支窗口小时数和蒸发能力等必要标识；不改变任何数据显示值。回放资料卡展示当前方案、时段与计算尺度。

## 核验

生产构建通过，既有10项前端工作流测试通过。浏览器检查了业务导航、监测查询与明细、内置和用户成果、模型资料、工作区、帮助及维护入口的打开与收起。模型实现和标准方案摘要与已发布最终成果一致。
